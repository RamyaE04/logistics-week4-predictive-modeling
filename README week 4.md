# Week 4: Predictive Modeling for Logistics

This project compares a median baseline, Linear Regression, and Random Forest to predict shipment delivery time using Python and scikit-learn. It evaluates models using MAE, RMSE, and R² and saves predictions, metrics, and charts.

## Files
- `week4_predictive_modeling.py` — dedicated Week 4 model script
- `logistics_shipments_clean.csv` — simulated educational shipment data
- `week4.docx` — Week 4 report
- `requirements.txt` — Python dependencies
- `weekly_submission_descriptions.txt` — internship report description text

## Run
Install dependencies:
```bash
python -m pip install -r requirements.txt
```
Run the script from this folder:
```bash
python week4_predictive_modeling.py
```
Results are saved in `week4_outputs/`.

**Data note:** The dataset is simulated for educational purposes and does not represent actual company shipment records. Model metrics are generated when the script runs and should not be assumed in advance.
